# ⚡ Siber Geliştirici Portalı (Cyberpunk Portal)

Sıradışı arayüz mimarisine sahip, interaktif ve hafif web projesi.

## 🚀 Özellikler
- **Canvas Arka Planı:** JavaScript ile dinamik akan matrix/binary kod efekti.
- **Terminal Arayüzü:** İnteraktif iletişim konsolu ve futuristik form yapısı.
- **Saf Teknolojiler:** Herhangi bir kütüphane veya framework kullanılmadan tamamen HTML5, CSS3 ve JavaScript (ES6+) ile geliştirilmiştir.

## 📁 Proje Klasör Yapısı
